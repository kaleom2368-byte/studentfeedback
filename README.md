# Anonymous Student Feedback System

## Overview

The Anonymous Student Feedback System is a web application developed using Node.js, Express.js, MySQL, HTML, CSS, and JavaScript. It allows students to submit anonymous feedback about faculty members while providing dashboards for Faculty, HOD, and Admin.

---

## Features

- Student Registration & Login
- Faculty Login
- HOD Login
- Admin Login
- Student Dashboard
- Faculty Dashboard
- HOD Dashboard
- Admin Dashboard
- Anonymous Feedback Submission
- MySQL Database

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MySQL

---

## Installation

```bash
npm install
node server.js
```

Open:

```
http://localhost:3000
```
